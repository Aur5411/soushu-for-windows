# 搜书吧 电脑版

Discuz! X3.4 小说论坛的 Windows 桌面客户端。自带 Chromium 内核与脚本引擎，
开箱即用：**附件一键后台下载、回复可见自动解锁、地址发布页自动跳转**。

```
v1.2.14
```

> **下载**：到 [Releases](https://github.com/Aur5411/soushu-for-windows/releases) 拿最新版。
> 发布页上的文件名是纯 ASCII 的 `soushuba-<版本>-Setup.exe` / `soushuba-<版本>-portable.exe`
> （避免各种下载器对中文名处理不一致），就是本文里说的
> `搜书吧-<版本>-Setup.exe` / `搜书吧-<版本>-portable.exe`，同一个东西。

> 这是 Android 版搜书吧（`ssapp`）的电脑版。两个平台不一样，移动端特有的兜底
> （双通道下载器、内置 TXT 阅读器、下拉刷新等）在桌面没有必要，没有照搬。

## 主要功能

### 下载

- 帖子页点附件**即下载**，不弹确认框
- **弹窗链接也一律后台静默下载**：论坛很多附件是 `target="_blank"` / `window.open`
  打开的，这类链接**不会新开页面**，直接在后台下好落到 `Download`，帖子页原地不动；
  `about:blank` / `javascript:` 这种空中转弹窗直接吞掉。只有真正的普通链接才开新标签页
- **`.txt` 也当文件下载**：论坛常把小说正文当纯文本返回，不拦就会在标签页里显示成
  一堆文字；拦下来存成文件，点开就是记事本
- 文件名**优先取帖子标题**（Discuz 的附件名常是乱码或纯数字），自动去掉
  `[sxsy.org]`、`www.xxx.com_` 这类站点标记；没后缀时按 Content-Type / 文件头补全
- **乱码自动修复**：服务器按 GBK 发文件名、浏览器按 Latin-1 解出来的 `¡¾Íê½á¡¿¶·ÆÆ²Ôñ·`
  这类乱码会按原始字节重新解码（GB18030 / Big5）修回中文；正常文件名不会被乱改
- 统一存到**软件文件夹下的 `Download`**（便携版就是 exe 所在那个文件夹），
  同名自动加 `(1)(2)`，下载位置可在设置里改
- 窗口最下方的**状态栏实时显示下载进度**：文件名 + 已下载/总大小 + 进度条 + 百分比；
  服务器没给长度时退化成来回跑的跑马灯（不假装有百分比）；下完/失败会停在绿色/红色
  的收尾状态几秒再消失
- 右上 `⤓ 下载 N` 打开**文件列表小浮窗**（点文件名用系统程序打开、点「定位」在资源管理器
  里选中），`📁` 直接打开本地下载文件夹

### 论坛地址

- 内置入口是搜书吧的**地址发布页**。发布页域名和结构会换，软件按「最新地址 / 搜书吧 /
  论坛」等关键词给页面上的链接打分，自动挑出真论坛跳过去，**不依赖易变的发布页 URL**
- 跳进去后记住真实域名，下次启动直达；换域名也可以在设置里手填

### 脚本引擎

不需要装 Tampermonkey，脚本直接从内核层注入。

- 注入时机是真 `document-start`（早于网页自身脚本），iframe 里同样注入
- 导入 `.user.js` / `.js` / `.txt`（txt 自动转成规范脚本），或点**新建脚本**直接开写
- 编辑器显示**完整源码**（含开头的 `==UserScript==` 元数据块），直接改 `@name` /
  `@match` / `@run-at` 都生效；输入框里右键或长按都能弹复制粘贴
- 每行脚本一个开关，**动一下右边页面立刻刷新**
- 已实现：`GM_setValue/getValue/deleteValue/listValues`、`GM_addValueChangeListener`、
  `GM_addStyle` / `GM_addElement` / `GM_log` / `GM_info`、`GM_openInTab` /
  `GM_notification` / `GM_setClipboard`、`GM_xmlhttpRequest`（走内核网络栈，
  **不受 CORS 限制、自带登录 cookie**）、`GM_download` / `GM_getResourceText`、
  `GM_registerMenuCommand`、`@require` / `@resource`（外链依赖自动下载并缓存）
- 同时支持 `GM.setValue(...)` 新式写法和 `unsafeWindow`

### 界面

**左侧只有脚本**：**导入脚本** / **新建脚本**两个按钮 + 脚本列表。
面板**默认一直开着**，不会自己收走 —— 只有两种情况才收起：点面板标题栏的 `‹`，
或者去点右边的网页。收起后变成窄条，鼠标移到左边缘或点最上面的按钮就展开；
窄条底部的 `⇥` 是「彻底固定」，连点网页都不收（再点一下恢复）。

**功能都在右上角**：脚本命中数 · **下载**（小浮窗列出文件）· **📁** 打开下载文件夹 ·
**⚙ 设置**（网站 / 下载位置 / 历史记录 / 缓存）。左下角只有两个排障小入口：
**兼容模式** 和 **打开日志**。

「缓存」可以一键清空网页缓存、代码缓存和脚本外链依赖 —— **不会退出登录**，
也不动历史记录、脚本和你下载的文件。

### 安全

- 证书错误只对搜书吧相关域名放行，其余一律拒绝
- 拦截跳转本地文件（`file://`）；**站外链接交给系统浏览器**打开
- 网页跑在沙箱里，脚本注入不影响主进程

## 内置脚本

随软件提供，**不占用你的脚本目录**，升级软件时跟着更新：

| 脚本 | 作用 | 开关 |
| --- | --- | --- |
| **自动回复解锁** | 「回复可见」内容静默回复并刷新解锁；61 秒冷却；**付费附件不碰** | 左侧列表里，带「内置」徽章 |
| **去广告** | 隐藏 Discuz 常见广告容器，并屏蔽帖子里的图片外显 | 恒开 |
| **浮层关闭修复** | 修「购买附件后登录/注册浮层关不掉」 | 恒开 |
| **附件失效自动重试** | 撞到「原附件链接已失效」提示页时自动点「重新下载」 | 恒开 |

内置脚本的源码只读（点「源码」能看，不能改也不能删），避免升级时被旧版覆盖。

## 数据位置

```
%APPDATA%\Soushuba\
  scripts\     脚本（.user.js，可直接用记事本改）
  cache\deps\  @require / @resource 下载的依赖缓存
  settings.json / state.json / compat.json
```

下载的文件在**软件文件夹下的 `Download`**，不在用户数据目录里。

## 自己编译

```bash
npm install
npm start          # 开发模式启动
npm run selftest   # 自动化自检（真实 Chromium + 内置本地服务器，不依赖外网）
npm run dist       # 打包 Windows exe
```

改了注入或论坛相关逻辑后，先跑 `npm run selftest`。Windows x64。

## 打不开怎么办

远程桌面、虚拟机、受限会话里 Chromium 的沙箱可能起不来（窗口一闪就退出）。
点左下角 **兼容模式** 切成「强制开启」再重启即可（无沙箱 + 软件渲染）。
默认是自动判断：上次启动崩过，下次会自动进兼容模式并记住。
