# 搜书吧 电脑版

Discuz! X3.4 小说论坛的桌面客户端。自带完整的 Chromium 内核与脚本引擎，
开箱即用：**附件一键下载、回复可见自动解锁、地址发布页自动跳转**。

```
v1.2.11
```

> **下载**：到 [Releases](https://github.com/Aur5411/soushu-for-windows/releases) 拿最新版。
> 发布页上的文件名是纯 ASCII 的 `soushuba-<版本>-Setup.exe` / `soushuba-<版本>-portable.exe`
> （避免各种下载器对中文名处理不一致），就是本文里说的
> `搜书吧-<版本>-Setup.exe` / `搜书吧-<版本>-portable.exe`，同一个东西。

> 这是 Android 版搜书吧（DiscuzForumApp）的电脑版。两个平台不一样，
> 移动端特有的一些兜底（双通道下载器、内置 TXT 阅读器、下拉刷新等）在桌面
> 没有必要，所以没有照搬 —— 详见文末「为什么没做这些」。

## 开箱即用

解压后双击 `搜书吧-1.2.11-portable.exe`（免安装），或运行 `搜书吧-1.2.11-Setup.exe` 安装。

打开就是论坛，不用配置。

### 内置了四个脚本

**它们随软件加载，不占用你的脚本目录**，升级软件时会跟着一起更新。

| 脚本 | 作用 | 开关在哪 |
| --- | --- | --- |
| **自动回复解锁** | 楼主 1 楼有「回复可见」内容时静默回复并刷新解锁；61 秒冷却倒计时；付费附件不碰 | **左侧脚本列表**（带「内置」徽章） |
| **去广告** | 隐藏 Discuz 常见广告容器，并屏蔽帖子里的图片外显 | 恒开 |
| **浮层关闭修复** | 修「购买附件后登录/注册浮层关不掉」（站点 jQuery 与 Discuz 的 `$` 冲突） | 恒开 |
| **附件失效自动重试** | 撞到「原附件链接已失效」提示页时自动点「重新下载」 | 恒开 |

「自动回复解锁」放在左侧列表里，是因为它最常需要临时停掉（比如想自己手动回复）。
点它那行的 **源码** 可以看完整代码（只读，内置脚本不能改也不能删，避免升级时被旧版覆盖）。

## 主要功能

### 论坛地址

内置入口是搜书吧的地址发布页。发布页的域名和页面结构会换，软件会按
「最新地址 / 搜书吧 / 论坛」等关键词给页面上的链接打分，自动挑出真论坛入口跳过去，
**不依赖易变的发布页 URL**。

跳进去之后会把真实域名记下来，下次启动直接进，不再走发布页。

换域名或想手动指定，点左侧 **⚙ 论坛设置** 填就行（不用写 `https://`，会自动补）。

### 下载

- 帖子页点附件**即下载**，不弹确认框
- **弹窗链接也一律后台静默下载**：论坛很多附件是 `target="_blank"` / `window.open`
  打开的，这类链接**不会新开页面** —— 直接在后台下好落到 `Download`，帖子页原地不动。
  如果是 `about:blank` / `javascript:` 这种空中转空弹窗，直接吞掉（不然就是一片空白页）。
  只有真正的普通链接才会开新标签页
- 文件统一存到**软件文件夹下的 `Download`**（便携版就是 exe 所在那个文件夹）
- 文件名**优先取帖子标题**（Discuz 的附件名常是乱码或纯数字），并自动去掉
  `[sxsy.org]`、`www.xxx.com_` 这类站点标记
- **`.txt` 链接一律当文件下载**：论坛常把小说正文当纯文本返回，不拦就会在标签页里
  显示成一堆文字；拦下来存成文件，点开就是记事本
- **文件名乱码自动修复**：论坛服务器常按 GBK 发文件名，浏览器按 HTTP 规范当 Latin-1 解，
  拿到的是 `¡¾Íê½á¡¿¶·ÆÆ²Ôñ·` 这种乱码。软件会按原始字节重新解码（GB18030 / Big5），
  修回中文书名；正常文件名不会被乱改
- **浏览历史**：自动记录访问过的页面，可搜索、可单条删除、可清空，点一条就回去
- 右上两个入口：`⤓ 下载 N` 打开**应用内文件列表**（点文件名用系统默认程序打开、
  点「定位」在资源管理器里选中），`📁` 直接打开本地下载文件夹
- 没有后缀时按 Content-Type / 文件头魔数补全（`.txt .zip .epub .pdf .rar .7z .mobi` …）
- 同名文件自动加 `(1)(2)`，不覆盖
- 下载位置在 **⚙ 设置 → 下载位置** 里改

### 脚本引擎

内置脚本引擎，不需要装 Tampermonkey 之类的扩展，脚本直接从内核层注入。

- 支持 `.user.js` / `.js` / `.txt` 导入（txt 会自动转成规范的 `.user.js`）
- 支持整段油猴脚本粘贴，元数据头自动解析
- **编辑器里显示完整源码**，含开头的 `==UserScript==` 元数据块；
  在里面直接改 `@name` / `@match` / `@run-at` 都会生效
  （保存时头由程序重新生成，不会越存越多）
- 输入框（源码 / 名称 / 论坛地址）里**右键或长按都能弹出剪切 · 复制 · 粘贴 · 全选**
  —— 触摸屏上长按粘贴也是走这个菜单
- **外部脚本目录**：直接监视你放脚本的文件夹（比如桌面的某个目录），
  不用导入复制，改了立即生效
- 注入时机是真 `document-start`，早于网页自身脚本；iframe 里同样注入

已实现的 GM API：

```
GM_setValue / GM_getValue / GM_deleteValue / GM_listValues
GM_addValueChangeListener / GM_removeValueChangeListener
GM_addStyle / GM_addElement / GM_log / GM_info
GM_openInTab / GM_notification / GM_setClipboard
GM_xmlhttpRequest（走内核网络栈，不受 CORS 限制、自带登录 cookie）
GM_download / GM_getResourceText / GM_getResourceURL
GM_registerMenuCommand（注册出来的命令显示在侧边栏）
@require / @resource（外链依赖自动下载并缓存）
```

同时也支持 `GM.setValue(...)` 新式写法和 `unsafeWindow`。

### 界面

**左侧只有脚本**：两个按钮（**导入脚本** / **新建脚本**）+ 你的脚本列表。

- **导入脚本**：选现成的 `.user.js` / `.js` / `.txt`（可多选）
- **新建脚本**：直接开一个空白编辑器，粘一段代码或从零写都行，不用先在硬盘上准备文件
- 每行脚本带「编辑」（内置脚本是「源码」，只读）和启用开关；开关一动，右边页面立刻刷新
- 不掺别的功能。不用时会**自动收起**成窄条，鼠标移到左边缘就展开；想一直展开，点窄条底部的 `⇥`。

**功能都收在右上角**：

| 位置 | 功能 |
| --- | --- |
| 顶栏右侧 | 脚本命中数 · **下载**（带文件数，点开右上角小浮窗列出文件）· **📁** 打开本地下载文件夹 · **⚙ 设置** |
| 顶栏左侧 | 后退 / 前进 / 刷新 / 回论坛（`⌂`） |
| 底部状态栏 | 只显示提示消息 |

点「下载」弹的是**右上角的小浮窗**（约 340px 宽、跟着内容长），不是占半个屏幕的抽屉。

**设置**四块：**网站**（论坛地址 / 启动直达 / 站外链接）、**下载位置**、**历史记录**、**缓存**。

「缓存」里可以一键清空 —— 只清网页资源缓存、代码缓存和脚本外链依赖；
**不会**退出登录，也不动历史记录、脚本和你下载的文件。

**左下角**只有两个排障用的小入口：**兼容模式**（软件打不开时切「强制开启」）和 **打开日志**（出问题时把日志发给我）。

> 底部状态栏是特意留的一条 DOM 区域。网页是原生图层，会盖住一切 DOM 浮层，
> 所以提示**只能**放这里 —— 放在别处（比如左下角浮层）会「看不见」或「显示不全」。

### 安全

- 证书错误只对搜书吧相关域名放行，其余一律拒绝
- 拦截页面跳转本地文件（`file://`）
- **站外链接交给系统浏览器**打开，避免这个窗口变成通用浏览器
- 网页运行在沙箱里，脚本注入不影响主进程

## 兼容模式

有些环境（远程桌面、虚拟机、受限会话）里 Chromium 的沙箱进程起不来，
表现为窗口一闪就退出、日志里出现 `GPU process isn't usable. Goodbye.`。

点工具栏的 **⚙**（老版）或命令行 `--compat` 可以关掉沙箱并改用软件渲染。
默认是「自动判断」：上次启动崩过就下次自动进兼容模式并记住。

## 开发

```bash
npm install
npm start          # 开发模式启动

npm run selftest   # 自动化自检（29 项，用真实 Chromium 跑）
npm run dist       # 打包 Windows exe
```

`npm run selftest` 自带一个本地 HTTP 服务器，不依赖外网，覆盖：
注入时机（真的早于网页脚本）、`@match` 过滤、iframe 注入、`document-end` 时机、
stop/enable 生效、GM 存储与变更监听、跨域请求、菜单命令、剪贴板、
`.txt` 转换、外部目录加载、**你的真实下载脚本在模拟帖子页上生效**、
发布页链接挑选与跳转、下载文件名处理、下载目录解析。

改任何注入或论坛逻辑后先跑它。

## 为什么没做这些

从 Android 版移植时，有几块**故意没搬**，因为它们治的是移动端 WebView 的毛病：

| 移动端功能 | 为什么桌面不需要 |
| --- | --- |
| 双通道下载器（原生 + 页面 fetch 回传） | WebView 的重定向/Cookie 处理不完善才需要自己兜；Chromium 下载引擎本来就稳 |
| 内置 TXT 阅读器 | **已确认不做**。txt 存成文件，点开就是电脑上的记事本 |
| App 内下载管理页 | 桌面有资源管理器 |
| 文件名乱码重编码（4×4 编码穷举） | 那是 WebView 对 GBK `Content-Disposition` 处理不完善的产物 |
| 下拉刷新 / 进度条 / 返回键退历史 | 桌面有 F5、Alt+← |
| 免银币链接解析 | 按你的要求改为外置脚本处理 |

内容层面的修复（去广告、图片屏蔽、自动回复、附件重试）跟平台无关，这些都保留了。

## 已知限制

- 只在自带的内核里生效，不影响系统上已装的 Chrome/Edge
- 免银币下载依赖你的外置脚本改写链接，软件只负责把下载接好
- 脚本跑在页面主世界（相当于油猴 `@grant none`），`GM_*` 挂在 `window` 上
- 发布页自动跳转只在「冷启动进论坛」那段窗口内生效，进了论坛就停手
  （否则帖子页的「首页」链接会被误点）
